## 三大改进模块详细结构

### 🔷 改进1: C3k2_PFAE (频率域增强) - Layer 2, 4, 6, 8

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                          C3k2_PFAE 完整结构                                  │
├─────────────────────────────────────────────────────────────────────────────┤
│                                                                              │
│  Input [B, C, H, W]                                                          │
│    ↓                                                                         │
│  Conv(1×1) → [B, 2×C', H, W]  (C' = C×e, e=0.5)                            │
│    ↓                                                                         │
│  Split into (2+n) branches:                                                  │
│    ├─ Branch 1: [B, C', H, W] ────────────────────────┐                     │
│    ├─ Branch 2: [B, C', H, W] ────────────────────────┤                     │
│    └─ Branch 3~n: → Bottleneck_PFAE × (n-2)           │                     │
│                      ↓                                 │                     │
│         ┌──────────────────────────────────────────┐  │                     │
│         │      Bottleneck_PFAE 内部                │  │                     │
│         │  ┌────────────────────────────────────┐  │  │                     │
│         │  │ Conv(1×1) → [C'×e]                 │  │  │                     │
│         │  │   ↓                                 │  │  │                     │
│         │  │ ╔═══════════════════════════════╗  │  │  │                     │
│         │  │ ║      PFAE Module              ║  │  │  │                     │
│         │  │ ╠═══════════════════════════════╣  │  │  │                     │
│         │  │ ║ Input [C'×e] → Down Conv      ║  │  │  │                     │
│         │  │ ║   ↓                            ║  │  │  │                     │
│         │  │ ║ [C'×e/2] → 6 Parallel Branches║  │  │  │                     │
│         │  │ ║                                ║  │  │  │                     │
│         │  │ ║ Branch 1: Conv(1×1)           ║  │  │  │                     │
│         │  │ ║   ↓ [C'×e/4]                  ║  │  │  │                     │
│         │  │ ║                                ║  │  │  │                     │
│         │  │ ║ Branch 2: Conv(3×3, d=3)      ║  │  │  │                     │
│         │  │ ║   ↓                            ║  │  │  │                     │
│         │  │ ║   FFT2D → Frequency Domain    ║  │  │  │                     │
│         │  │ ║   ↓                            ║  │  │  │                     │
│         │  │ ║   8-Head Attention:           ║  │  │  │                     │
│         │  │ ║     Q = FFT(x), K = FFT(x)    ║  │  │  │                     │
│         │  │ ║     V = FFT(x)                ║  │  │  │                     │
│         │  │ ║     Attn = Softmax(Q·K^T/T)   ║  │  │  │                     │
│         │  │ ║     Out = Attn · V            ║  │  │  │                     │
│         │  │ ║   ↓                            ║  │  │  │                     │
│         │  │ ║   IFFT2D → Spatial Domain     ║  │  │  │                     │
│         │  │ ║   ↓                            ║  │  │  │                     │
│         │  │ ║   + Local Attn (Weight×FFT)   ║  │  │  │                     │
│         │  │ ║   ↓                            ║  │  │  │                     │
│         │  │ ║   + Residual → [C'×e/4]       ║  │  │  │                     │
│         │  │ ║                                ║  │  │  │                     │
│         │  │ ║ Branch 3: Conv(3×3, d=5)      ║  │  │  │                     │
│         │  │ ║   + Freq Attn (同Branch 2)    ║  │  │  │                     │
│         │  │ ║   ↓ [C'×e/4]                  ║  │  │  │                     │
│         │  │ ║                                ║  │  │  │                     │
│         │  │ ║ Branch 4: Conv(3×3, d=7)      ║  │  │  │                     │
│         │  │ ║   + Freq Attn (同Branch 2)    ║  │  │  │                     │
│         │  │ ║   ↓ [C'×e/4]                  ║  │  │  │                     │
│         │  │ ║                                ║  │  │  │                     │
│         │  │ ║ Branch 5: Conv(3×3, d=9)      ║  │  │  │                     │
│         │  │ ║   + Freq Attn (同Branch 2)    ║  │  │  │                     │
│         │  │ ║   ↓ [C'×e/4]                  ║  │  │  │                     │
│         │  │ ║                                ║  │  │  │                     │
│         │  │ ║ Branch 6: AdaptiveAvgPool     ║  │  │  │                     │
│         │  │ ║   → Conv(1×1) → Upsample      ║  │  │  │                     │
│         │  │ ║   ↓ [C'×e/4]                  ║  │  │  │                     │
│         │  │ ║                                ║  │  │  │                     │
│         │  │ ║ Concat all 6 branches         ║  │  │  │                     │
│         │  │ ║   ↓ [6×C'×e/4]                ║  │  │  │                     │
│         │  │ ║ Fuse Conv → Out Conv          ║  │  │  │                     │
│         │  │ ║   ↓ [C'×e]                    ║  │  │  │                     │
│         │  │ ╚═══════════════════════════════╝  │  │  │                     │
│         │  │   ↓                                 │  │  │                     │
│         │  │ + Residual (if shortcut)            │  │  │                     │
│         │  └────────────────────────────────────┘  │  │                     │
│         └──────────────────────────────────────────┘  │                     │
│    ↓                                                   │                     │
│  Concat all branches → Conv(1×1) → [B, C, H, W] ──────┘                     │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```
